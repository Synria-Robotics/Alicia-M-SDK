# 通信协议快速参考

基于《云擎通讯协议 v1.0.0》，本文档提供 SDK 开发所需的协议要点。

## 帧结构

```
[0xAA] [cmd_id] [func_code] [length] [data...] [CRC8] [0xFF]
  帧头    指令ID    功能码    数据长度   有效数据   校验位   帧尾
```

**校验位**: `CRC32(cmd_id + func_code + length + data) & 0xFF`

使用 `binascii.crc32()` 标准库实现。

## 指令 ID 总览

| ID | 功能 | SDK 方法 |
|----|------|---------|
| `0x01` | 版本信息 | `get_firmware_version()` |
| `0x03` | 零位标定 | `set_zero_position()` |
| `0x05` | 力矩开关（仅 MIT） | `torque_control()` |
| `0x06` | 关节状态读写（核心） | `set_robot_state()` / `get_robot_state()` |
| `0x09` | 使能/失能 | `enable_robot()` / `disable_robot()` |
| `0x11` | 电机参数设置 | `switch_mode()` |
| `0xEE` | 错误反馈 | 自动处理 |

## 功能码规则

| bit | 含义 |
|-----|------|
| bit7 | `0`=读取, `1`=写入 |
| bit0 | `1`=示教臂 |
| bit1 | `1`=操作臂 |

示例: `0x82` = 写入操作臂, `0x01` = 读取示教臂

## 0x06 关节数据地址表

| 地址 | 内容 | 位数 | 物理范围 |
|------|------|------|---------|
| `0x00` | 位置 | 16 bit | ±12.5 rad |
| `0x01` | 速度 | 12 bit | ±10.0 rad/s |
| `0x02` | 力矩 | 12 bit | 大关节 ±28 / 小关节 ±10 N·m |
| `0x03` | Kp | 16 bit | [0, 500] |
| `0x04` | Kd | 16 bit | [0, 5] |
| `0x05` | 线性轨迹速度 | 12 bit | ±10.0 rad/s |

## PV 帧 vs MIT 帧

| | PV | MIT |
|--|----|----|
| addr_count | 2 | 5 |
| 每电机字节 | 4 (pos+vel) | 10 (pos+vel+torque+kp+kd) |
| 总帧长 | 36B | 78B |
| 数据长度字节 | 0x1E | 0x48 |

## 数据映射

```
协议值 = (物理值 - 下限) / (上限 - 下限) × (2^位数 - 1)
```

所有多字节数据: **小端序**。
12 bit 数据: 高 4 位置零，低 12 位有效。

## 模式切换 (0x11)

```
addr = 0x0B
MIT: mode = 0x01 0x00 0x00 0x00
PV:  mode = 0x02 0x00 0x00 0x00
```

## 运行状态字节

| bit | 示教臂 | 操作臂 |
|-----|--------|--------|
| 0 | 锁定 | 单击 |
| 1 | 同步 | 双击 |
| 2-5 | 待定 | 长按/待定 |
| 6 | 夹具力矩锁定 | 夹具力矩锁定 |
| 7 | 电机错误 | 电机错误 |
